# Brand marks

`claude.png`, `gemini.png` and `openai.png` are white silhouettes rendered at 96x96 from Simple Icons 13.21.0
(`claude.svg`, `googlegemini.svg`, `openai.svg`; https://simpleicons.org), which releases its icon data under
CC0-1.0. The desktop app tints them in each brand's colour and shows them only to name the app a tab links to.

The marks themselves are trademarks of Anthropic, Google and OpenAI respectively. Kickstand isn't affiliated
with or endorsed by any of them.
